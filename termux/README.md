# fadaa: من فضاء الروايات إلى EPUB

أداة صغيرة تنزّل فصول رواية من [فضاء الروايات](https://cenele.com/) وتسوي منها ملفات EPUB عربية مضبوطة:

- غلاف JPG يظهر في كل أجهزة القراءة
- النص والصفحات من اليمين لليسار، ومسافة بين كل فقرة والثانية
- فهرس مقسّم على المجلدات، وتقدر تخلي كل مجلد في ملف لحاله
- صفحة عنوان فيها المؤلف والمترجم والموقع
- الفصول تنحفظ في جوالك، فالمرة الجاية ينزّل الجديد بس
- تقدر ترسل الملفات للكيندل (KOReader) لاسلكياً

## التثبيت في الجوال (مرة وحدة)

1. نزّل **Termux** من [F-Droid](https://f-droid.org/packages/com.termux/). النسخة اللي في Google Play قديمة.
2. افتح Termux والصق هذا السطر، واضغط Enter:
   ```
   pkg install -y curl && curl -fsSL https://raw.githubusercontent.com/omor0y/my-novel-repo/main/termux/install.sh | bash
   ```
3. لما يطلب منك صلاحية التخزين، اضغط **سماح**.

ولو تبغى تحدّث الأداة بعدين، الصق نفس السطر مرة ثانية.

## الاستخدام

افتح صفحة الرواية في المتصفح، واضغط **مشاركة**، واختر **Termux**. بعدها:

- يعرض لك المجلدات. اضغط Enter عشان تنزّل الكل، أو اكتب أرقامها مثل `1 3` أو `2-5`.
- يسألك إذا تبغى ملف لكل مجلد. اضغط Enter للموافقة.
- الملفات تطلع في مجلد التنزيلات، داخل `Download/Fadaa/اسم الرواية`.

ومن داخل Termux تقدر تكتب:

```
fadaa https://cenele.com/cont/shadow-novel/
fadaa https://cenele.com/cont/shadow-novel/ --volumes 13 --send
```

## الإرسال للكيندل (KOReader)

1. في الكيندل افتح KOReader، ورح للإعدادات ← الشبكة ← SSH server. فعّل **Login without password**، وشغّل الخادم.
2. في Termux اكتب `fadaa --setup-kindle`، وحط عنوان الـ IP اللي طلع في الكيندل.
3. بعدها كل مرة بيسألك: «إرسال للكيندل؟». الملفات توصل لمجلد `Fadaa` داخل `documents`.

لازم الجوال والكيندل يكونون على نفس شبكة الواي فاي.

## على الماك أو الكمبيوتر

```
pip3 install requests beautifulsoup4 pillow
python3 fadaa.py https://cenele.com/cont/shadow-novel/
```

## ملاحظات

- الأداة تطلب الصفحات وحدة وحدة، وتنتظر ثانية بين كل طلب والثاني.
- إذا طلب الموقع تحقق «لست روبوت»، الأداة توقف التحميل على طول، وتسوي الملف من الفصول اللي نزلت قبل. هذا التحقق من الموقع نفسه، والأداة ما تتجاوزه.
- الترجمة حق مترجمي فضاء الروايات، والأداة للقراءة الشخصية.
